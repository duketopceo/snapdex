# snapdex brand (proposal)

Hand-written SVG, no raster or generated art. The owner signs off logos; treat these as a proposal.

- `logo.svg` / `logo-dark.svg`: 64x64 grid. Four 16-unit L-shaped crop corners (stroke 6, square caps) frame a capture; the centred 28x8 bar is a caption line, the thing snapdex adds. Legible at 16 px (the bar stays 2 px).
- `wordmark.svg`: mark plus "snapdex" in a bold monospace (falls back to Adwaita Mono or DejaVu Sans Mono), echoing the snake_case filenames.
- Colours: ink `#1B1F23` / `#EDEAE2` (dark), accent `#C2410C` / `#FB923C`.
- `preview.png` is rendered with `resvg`.
